# Классификация горных пород

Система объединяет экспертный решатель на базе правил и отдельный ML-модуль. Экспертная классификация выполняется по методу опровержения гипотез, а ML-модель используется только по отдельному запросу пользователя через кнопку «Спросить ML-модель».

## Возможности

- главное меню при запуске приложения;
- переход из главного меню в редактор базы знаний;
- переход из главного меню в режим классификации пород;
- переобучение ML-модели из главного меню;
- возврат в главное меню из рабочих экранов;
- редактирование базы знаний: породы, свойства, допустимые значения, описание свойств вида и значения для вида;
- проверка полноты базы знаний;
- классификация породы по экспертным правилам без автоматического запуска ML;
- отдельный запрос к ML-модели независимо от результата экспертной классификации;
- вывод объяснений: подходящие породы и причины опровержения остальных гипотез;
- вывод оценок ML-модели без нулевых вероятностей.

## Логика работы

### Экспертная классификация

Кнопка «Определить вид породы» запускает только экспертный решатель. Система сравнивает введённые свойства образца с описаниями пород в базе знаний и формирует список подходящих видов.

Возможные результаты:

- не введены данные — система просит заполнить хотя бы одно свойство;
- есть ошибки ввода — система показывает, какое значение некорректно;
- нет подходящих пород — все гипотезы опровергнуты;
- найдена одна подходящая порода — выводится однозначный результат;
- найдено несколько подходящих пород — выводится список кандидатов, но ML автоматически не запускается.

### ML-классификация

Кнопка «Спросить ML-модель» запускает отдельную классификацию с точки зрения обученной модели. ML можно запросить в любом случае: при одном найденном экспертном варианте, при нескольких вариантах или просто после ввода признаков.

ML-результат не заменяет экспертный решатель. Он выводится отдельно как дополнительная оценка модели. В списке вероятностей отображаются только ненулевые значения, чтобы не перегружать окно результата.

### Переобучение модели

Кнопка «Переобучить модель» находится в главном меню. Она обучает модель заново на текущей базе знаний и сохраняет результат в файл `models/rock_classifier_mlp.joblib`.

Также доступен консольный запуск переобучения:

```bash
python train_model.py
```

## Запуск

### Через bat-файл на Windows

```bat
run_app.bat
```

### Через Python

```bash
python app.py
```

## Зависимости

Проект использует Python 3.10+ и следующие библиотеки:

- `pandas`;
- `scikit-learn`;
- `joblib`.

Установка зависимостей:

```bash
pip install pandas scikit-learn joblib
```

## Пример входных данных

Для проверки классификации можно использовать значения:

```text
Происхождение: магматическая
Структура: кристаллическая
Минеральный состав: полевошпатовый
Плотность: 2.95
```

Экспертный решатель должен найти подходящую породу на основе правил базы знаний. ML-модель можно запросить отдельно через кнопку «Спросить ML-модель».

## Примечания

- Обычная классификация не запускает ML автоматически.
- Переобучение модели вынесено из окна классификации в главное меню.
- Если модель не загружена, экспертный решатель всё равно продолжает работать.
- После изменения базы знаний модель желательно переобучить, чтобы ML-оценка соответствовала актуальным данным.
